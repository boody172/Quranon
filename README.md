# قرآنون — تطبيق القرآن الكريم

تطبيق ويب (PWA) يعمل على الموبايل ويُثبَّت كتطبيق، بالعربية بالكامل (RTL).

## الأقسام
| القسم | المحتوى |
|---|---|
| الرئيسية | آية اليوم، تابع من حيث توقفت (استماع + قراءة)، أعلام التلاوة، اختصارات |
| استمع | كل قراء mp3quran.net (+٢٠٠ قارئ) مع فلترة حسب الدولة (مصر، السعودية، الكويت…)، «رحمهم الله»، المفضلة، كل الروايات لكل قارئ |
| الإذاعات | بث مباشر ٢٤ ساعة |
| المصحف | ١١٤ سورة بالرسم العثماني، تكبير الخط، حفظ موضع القراءة، «استمع للسورة» |
| دروس | علماء حسب الدولة + تفسير صوتي سورة بسورة |
| القبلة | بوصلة حية بالموقع والمستشعر، تهتز وتضيء عند الاتجاه الصحيح، المسافة إلى مكة |

المشغل: تشغيل في الخلفية مع أزرار شاشة القفل، تكرار (سورة/قائمة)، سرعة، مؤقت نوم، تحميل، الاستكمال من آخر موضع.

## التشغيل
```bash
npx serve .        # أو: python3 -m http.server 8000
```
ثم افتح `http://localhost:8000` (البوصلة تحتاج HTTPS على الموبايل — انشره على Netlify/Vercel/GitHub Pages).

## مصادر البيانات
- الصوتيات والقراء والإذاعات والتفسير: `mp3quran.net/api/v3`
- نص المصحف: `api.alquran.cloud`

## تعديل التصميم
كل الألوان والخطوط في أول `css/style.css` تحت `:root`. تصنيف القراء حسب الدولة والعلماء في `js/data.js`.
